# Lumen Desk 产品说明

## 1. 产品定位

Lumen Desk 是面向中小团队的 AI 客服知识库工作台。它把团队现有的文档、FAQ 和操作手册整理成可检索的知识，客服人员在一个对话框里提问，就能得到带来源引用的回答。

目前支持的服务渠道：邮件、网页在线聊天、WhatsApp。产品以 Web 工作台为主，不提供电话语音客服，也没有独立移动端 App。

## 2. 文档与知识库

支持的文本格式：Markdown、TXT、CSV。图片（PNG、JPG）可以上传并用于预览或工单附件，但不参与向量检索。

上传后的处理流程：

1. 统一换行并去除首尾空白。
2. 按 800 字符切块，块与块之间保留 120 字符重叠。
3. 每个块调用 embedding-3 生成 1024 维向量。
4. 向量写入 PostgreSQL 的 pgvector 字段，原文同时保留。

套餐默认限制：单文件不超过 10 MB，单次最多携带 3 个附件，文本内容不超过 20 万字符。不同套餐的差异见 `03-limits.csv`。

如果部分块向量化失败，文档状态会变成 `PARTIAL`，并记录失败块数；全部失败则为 `FAILED`，可以删除后重新上传。

## 3. 检索与回答

提问时按固定顺序取数：

1. 本轮附件（如果用户上传了文件，只在附件范围内检索）。
2. 当前工作区的文档。
3. 联网搜索（仅当用户显式打开开关时才调用）。

检索使用余弦距离，取 Top-5，距离阈值 0.55。只有低于阈值的块才会进入上下文；不会把无关内容硬塞给模型。

如果本地检索和联网都没有结果，系统直接返回固定文案：

> 当前知识库没有找到依据，请补充资料或开启联网搜索。

这种情况下不会调用大模型，避免模型用通用知识编造答案。

回答中的来源使用 `[1]`、`[2]` 这样的角标标注，前端会渲染成可点击的引用，并在回答下方列出来源标题。历史消息里的来源同样可以点击。

## 4. 套餐与限制

| 项目 | Starter | Growth | Enterprise |
| --- | --- | --- | --- |
| 席位数 | 3 | 10 | 50 |
| 每月回答数 | 1,000 | 10,000 | 100,000 |
| 存储空间 | 2 GB | 20 GB | 200 GB |
| 数据保留 | 30 天 | 90 天 | 365 天 |
| 退款周期 | 14 个工作日 | 7 个工作日 | 30 个工作日 |

退款说明：如果合同没有单独约定，默认按 14 个工作日处理；套餐表中有明确约定的，以套餐表为准。

对话限流为每分钟 10 次，上传限流为每分钟 20 次。API 的每分钟请求上限随套餐变化，具体数值见 `03-limits.csv`。

## 5. 错误格式

所有 API 错误使用统一结构：

```json
{
  "error": {
    "code": "RATE_LIMITED",
    "message": "请求过于频繁，请稍后再试"
  }
}
```

常见错误码：

- `UNAUTHORIZED`：未登录或 API Key 无效
- `VALIDATION_ERROR`：请求参数不合法
- `RATE_LIMITED`：触发限流
- `NO_BASIS`：知识库没有可用依据
- `INTERNAL`：服务端异常

## 6. 数据与安全

- 所有查询都带工作区标识，成员只能访问所属工作区的文档。
- 日志不记录完整文档内容、密码、Cookie 和 API Key。
- 删除对话只会解除文档与对话的关联，不会删除已经上传的文档。
- 成员被移出工作区后，无法再通过历史链接访问该工作区的对话。

## 7. 计费与发票

套餐按月计费，超出每月回答数后按每千次回答 8 美元计费。发票在账单周期结束后 3 个工作日内生成，可在工作台下载。
